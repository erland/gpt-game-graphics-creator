# Release Notes — 1.0.0-rc2

## Current scope

This release candidate contains the current Game Graphics Creator Builder configuration, 13 approved permanent Knowledge files, request/delivery contracts, schemas/templates, reusable Preview fixtures, and regression tests G01–G16.

It also includes synchronized Custom GPT and portable Chat distribution tooling.

## Validation status

Automated distribution build and validation pass for the current package. GPT Preview cases G01–G16 remain the authoritative manual regression suite and must be executed before broader publication.

## Deferred / external verification

Production-quality image generation, identity consistency, runtime integration, SpriteKit behavior, TV readability and physical-device behavior require manual or external verification where applicable.

## Repository maintenance

Prompt-by-prompt implementation result files and historical preflight snapshots are intentionally not kept in the current working tree. Git history is the source for those development records.
