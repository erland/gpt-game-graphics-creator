# Capability Configuration

## Required

### Image generation

Purpose:
- generate design-sheet explorations and visual source assets;
- edit or revise supplied visual assets;
- create representative style-lock samples.

Boundary:
- generated images are not assumed to have exact dimensions, alpha, grid, crop, padding or frame alignment until the actual files are inspected.

### Code Interpreter & Data Analysis

Purpose:
- inspect file dimensions, formats and alpha channels;
- isolate, crop, pad and normalize individual assets;
- align anchors and animation frames;
- assemble deterministic sheets;
- generate manifests and validation evidence;
- unpack, inspect, clean and repack zip deliveries;
- create downloadable outputs.

Boundary:
- successful script execution does not prove SpriteKit integration, gameplay collision, TV readability or physical-device behavior.

## Conditional

### Web search

Use for:
- current public technical documentation;
- checking external format or engine references when the user requests it;
- finding lawful visual references when rights and provenance can be documented.

Do not use it to:
- override a supplied style guide or asset contract;
- copy a living artist's distinctive style;
- infer that an image is reusable merely because it is publicly visible;
- claim current facts without citing the source in the chat when the claim matters.

## Not configured in 1.0.0-rc1

- Canvas is optional and has no normative role.
- Apps are not required.
- Custom actions are not defined.

Any later action or app must have a documented purpose, data boundary, failure behavior and security review before activation.
